SSD1306 oled driver library for monochrome 128x64 and 128x32 displays. Original author: Adafruit. This is my working copy from the Arduino `libraries` tree. Version recorded in `library.properties`: 2.5.1. Upstream: <https://github.com/adafruit/Adafruit_SSD1306>.

## How to open

Install this folder as an Arduino library (Sketch → Include Library → Add .ZIP Library, or copy into `libraries/Adafruit_SSD1306`). Open any `examples/*.ino` from the Arduino IDE.
